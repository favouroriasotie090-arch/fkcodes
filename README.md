# FK Codes Portfolio

Personal portfolio website for **Favor Oriasotie Omoabure**, developer brand **FK Codes**.

## Files

- `index.html` — portfolio structure/content
- `style.css` — responsive visual design
- `main.js` — navigation, theme switcher, project modals, scroll reveal and copy-email interaction
- `assets/profile.jpg` — supplied profile image

## Run it

Open `index.html` in a browser. No build step is required.

## Design notes

The portfolio uses a dark, code-inspired visual system with a mobile-first responsive layout, project case-study modals, a light/dark theme toggle and subtle motion.

The project descriptions deliberately distinguish concept/learning projects from production client work so the portfolio doesn't accidentally claim work that hasn't been completed or deployed.
